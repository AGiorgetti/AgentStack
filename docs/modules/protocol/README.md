# Protocol Module

The `protocol` module installs AgentStack Protocol: repository-local assets, tracker mappings, policy, and skills for autonomous agents collaborating with humans through backlog items.

Install:

```sh
agentstack setup protocol --tracker github --github-repository OWNER/REPO
```

Uninstall:

```sh
agentstack uninstall protocol
```
